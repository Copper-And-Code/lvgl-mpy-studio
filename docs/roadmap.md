# Roadmap

Goal: become the best tool for LVGL on MicroPython. The IDE stays as comfortable as Visual Basic, while the generated code is plain, compact and fast LVGL, with no runtime layers.

The target on boards is MicroPython; C on boards is postponed.

## Competitors (research from 2026-11-06)

| Tool | Strengths | Limits found |
|---|---|---|
| LVGL Pro | Official, XML editor, Figma, CLI for CI | Community plan for personal use only and without CLI; Product plan at $20,000 per product; the pricing page does not mention MicroPython |
| SquareLine Studio | Mature, exports C and MicroPython | Subscription; an undated post reports MicroPython support for LVGL v8 only, to be rechecked |
| EEZ Studio | Open source, flow-based logic, LVGL 8 and 9 | One user found it unintuitive; MicroPython support not confirmed |
| GUI Guider (NXP) | Free | Tied to NXP microcontrollers |

Review before public use: prices and features change, and MicroPython support in LVGL Pro and EEZ Studio has not been confirmed.

## Distinctive features

### Debugging in the simulator
An Immediate window, variables and errors that lead to the right handler. Check first whether the runtime allows breakpoints.

### Widget arrays
An idea from Visual Basic: draw a grid and use `ui.cell[i]` in code, generated by a loop instead of hundreds of single widgets.

## Further compaction

- **Pages created on demand:** today all pages are created at startup and use RAM even if never opened.

## Parity to reach

- Reusable style and theme editor.
- Built-in font and image conversion, with only the characters in use.
- A project format that suits Git: readable diffs and separate code files.
- Figma import: expensive and less valuable for embedded users, so it comes last.
- Parameters shown while typing in the editor.
- Handlers written in C in the IDE, plus C build and flash on boards if needed.

## Designer polish

- Draw a control by dragging a rectangle on the form.
- Combo for the selected object at the top of Properties.
- Immediate window in the simulator.
- Whole-module view and the F7, Shift+F7 and F4 shortcuts.
- Procedure combo showing only the events that make sense for the widget type.
